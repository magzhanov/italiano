# Italiano

Italian language learning app for iPhone and desktop.

Open https://magzhanov.github.io/italiano/ in your browser.

## Install on iPhone

Open the site in Safari, tap Share, then Add to Home Screen. If Safari offers Open as Web App, leave it enabled.

## Progress and offline use

Progress is stored locally on each device. Use the app's Progress & sync export/import controls to transfer progress between devices. After the first successful online visit, the service worker caches the app for offline use. Italian speech playback depends on the voices available on your device.

## Hosting

GitHub Pages serves the static files from the main branch at the repository root. There is no build step. Keep index.html, sw.js, manifest.webmanifest, and the three icon files together.
